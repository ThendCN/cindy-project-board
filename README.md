# 项目看板（Project Board）

一个 Cindy 插件，在一个页面里总览项目的任务状态、项目介绍、待办、AGENTS.md 等资料和 Git 状态。

不用翻侧边栏和文件，就能看清一个项目「现在在干什么、接下来要干什么」。项目资料存放在项目自己的 `.cindy/` 目录里，随 git 提交，团队共享；既能在看板里直接编辑，也能一键让 AI 生成或更新。

## 主要功能

- **左侧项目栏**：点一下就切换项目，每个项目旁显示待处理、运行中、刚完成的任务数。
- **全部项目总览**：每个项目一张卡片，显示待处理与运行中的任务数、未完成待办数、分支与未提交改动、最近活动，等你处理的排在最前。
- **任务**：按状态分栏（待处理 / 运行中 / 刚完成 / 其他）显示项目内的 Cindy 任务，点击打开；订阅任务事件，状态变化即时刷新。
- **待办**：读写 `.cindy/todos.md`，支持勾选、改文字、删除、新增，可多选后一键交给 AI；派出去的待办旁显示对应任务的状态。
- **项目介绍**：显示并编辑 `.cindy/project.md`，保存前核对是否被别处改过。
- **资料库**：列出 `.cindy/project-knowledge/` 下的全部文档和文件，可上传、删除；Markdown、图片、PDF、文本、音视频直接在看板里预览，docx 等用电脑上的默认应用打开。收集的资料按条直接显示，可在看板里记一条、删一条，也可让 AI 整理维护。
- **知识候选**：点「提取知识」让 AI 从最近的工作里提出值得长期保留的知识，每条带依据；你逐条确认、修改或忽略，确认后才写进知识库并列入 `TOC.md`，新任务才能找到。
- **配置文件**：折叠在资料库底部，可直接查看和编辑 README、AGENTS.md、CLAUDE.md，也可让 AI 创建或维护；一键在 AGENTS.md 加入「项目资料」入口。
- **Git**：当前分支、未提交改动数、最近提交、其他 worktree。
- **从聊天记录**：给绑定了微信等渠道的伙伴发消息，让它把待办或资料记到对应项目；项目不明确就放进「收集箱」项目，也可以撤销或移动。
- 界面支持简繁中文、英、日、韩、西、法、德、葡（巴西 / 葡萄牙）语，跟随 Cindy 语言。

## 安装

在 Cindy 里用插件开发工具（`ghost_forge_pack` / `ghost_forge_install`）打包并安装 `project-board-plugin/`，然后打开「项目看板」主视图。首次使用需在插件详情页允许查看任务、新建任务。

## 测试

只用 Node 内置模块，无需安装依赖：

```sh
node --test tests/*.test.cjs
```

## 目录

- `project-board-plugin/`：插件源码（原生 HTML / CSS / JavaScript，无构建步骤；Node 工作进程只用内置模块和本机 `git`）
- `tests/`：Node 工作进程和插件工具的测试
- `.cindy/`：本项目自己的介绍和待办

详细说明见 [`.cindy/project.md`](.cindy/project.md)。

## 协作

不直接推送 `main`：从最新的 `main` 开分支，改完提 PR，跑过测试、由另一位维护者看过再合并。界面改动在 PR 里说明在 Cindy 中手动验证了什么。
